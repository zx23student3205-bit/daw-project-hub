# DAW Project Hub
Pequeña página web para practicar un flujo profesional de trabajo con Git y GitHub.
## Historial del proyecto

Realizar varios commits pequeños, atómicos y coherentes presenta múltiples ventajas frente a un único commit masivo:

* **Mayor trazabilidad:** Facilita identificar con precisión cuándo y por qué se introdujo una modificación o regla de estilo específica.
* **Aislamiento y revisión de errores:** Si un cambio introduce un fallo, se puede inspeccionar (`git show`) o revertir (`git revert`) ese commit en concreto sin perder el resto del trabajo realizado.
* **Facilidad en la revisión de código:** En entornos colaborativos, las revisiones (*pull requests*) resultan más ágiles y comprensibles para el equipo si los cambios están estructurados por tareas lógicas.
* **Mensajes descriptivos:** Obliga a documentar la evolución del desarrollo paso a paso, manteniendo una bitácora clara de la historia del proyecto.
